# rpi-procmon v0.3.1

Released October 21, 2026.

Fix overall health aggregation so monitor ordering cannot hide a degraded or failed service behind a recovering/checking monitor. Individual monitor states, read APIs, configuration, and recovery behavior remain unchanged.

This patch accompanies the Homebridge plugin reliability review. Homebridge clients should distinguish routine checking from failure using per-monitor completed-check evidence, mark stale/unreachable data unavailable, and preserve accessory identities across recovery.

Upgrade by rebuilding/installing the controller binary and restarting `rpi-procmon.service`. No bootstrap rerun or remote-agent installation is required. Preserve existing configuration and state/history.
